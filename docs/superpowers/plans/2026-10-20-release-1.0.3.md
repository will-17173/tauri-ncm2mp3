# Release 1.0.3 Build Plan

**Goal:** Build the updated desktop application, copy the installers into `site/`, and point the website's download cards at the verified files.

**Architecture:** Build macOS Universal (Intel and Apple Silicon) and Windows x64 NSIS installers from the existing 1.0.3 sources. Keep generated SDKs and compiler outputs under ignored `src-tauri/target/`. Build the frontend once and disable the duplicate frontend hook through temporary CLI configuration files.

**Tools:** Existing Tauri CLI, Rust targets, cargo-xwin, LLVM, NSIS, hdiutil, system Playwright and Chrome.

- [x] Verify versions, source status, available cross-compilers, and the website's active download handling.
- [x] Run `pnpm build` inside `app/`.
- [x] Build macOS with `pnpm tauri build --target universal-apple-darwin --bundles dmg --ci`, using a temporary config with `build.beforeBuildCommand = null` and `bundle.macOS.signingIdentity = "-"`.
- [x] Build Windows with `pnpm tauri build --runner cargo-xwin --target x86_64-pc-windows-msvc --ci`, using a temporary config with `bundle.targets = ["nsis"]` and `build.beforeBuildCommand = null`. Set LLVM's bin directory on PATH and use a separate ignored Cargo target directory.
- [x] Verify the macOS image, app version and universal architectures; verify the Windows executable and installer metadata. Run application checks on the available host and record any platform checks that cannot run here.
- [x] Copy `ncm2mp3_1.0.3_universal.dmg` and `ncm2mp3_1.0.3_x64-setup.exe` into `site/`, preserving existing release artifacts.
- [x] Update `site/index.html` download URLs, version labels, and sizes to match the generated artifacts.
- [x] Use the system Playwright installation to click both download buttons on a local server and compare downloaded file hashes with the artifacts. Re-run the website decoder tests and check the final diffs.

No publishing, Git commits, or remote uploads are part of this request.
